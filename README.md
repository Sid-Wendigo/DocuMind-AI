# DocuMind – AI-Powered PDF Assistant

DocuMind is an AI-powered PDF assistant that helps users understand, analyze, and explore PDF documents using Google's Gemini API.

## Features

- **PDF Analysis:** Upload and interact with PDF documents.
- **Guided Learning:** Understand complex concepts through simple explanations.
- **Executive Summary:** Extract key findings and important information.
- **Deep Research:** Explore detailed information, evidence, and supporting PDF references.
- **Page Citations:** Get PDF page references for document-based answers.
- **Interactive UI:** Suggested questions, chat interface, and conversation export.
- **Light and Dark Themes:** Theme-aware interface for comfortable reading.

## Tech Stack

- Python
- Streamlit
- Google Gemini API
- Google GenAI SDK
- Python Dotenv

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR_USERNAME/DocuMind-AI-PDF-Assistant.git
   cd DocuMind-AI-PDF-Assistant
   ```

2. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Create a `.env` file:

   ```env
   GEMINI_API_KEY=your_api_key_here
   ```

4. Run the application:

   ```bash
   streamlit run app.py
   ```

## Security

Never upload your `.env` file or expose your Gemini API key.
